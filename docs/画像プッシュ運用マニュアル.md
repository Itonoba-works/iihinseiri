## 1. 画像の追加・差し替え

### 置き場所とファイル名ルール

| 用途 | フォルダ | ファイル名 |
|---|---|---|
| ヒーロー画像（トップページ上部） | `public/images/hero/` | `home.jpg` |
| 記事カードのサムネイル | `public/images/categories/` | `{slug}.jpg` ※例：`akutoku.jpg` |
| 企業のサムネイル画像 | `public/images/companies/` | `{id}.jpg` ※例：`ihinnoseiriyasan.jpg` |

### 推奨サイズ（JPG・品質85%・1枚200KB以下）

| 用途 | サイズ | アスペクト比 |
|---|---|---|
| ヒーロー | 1200×900 px | 4:3 |
| 記事カード | 800×500 px | 16:10 |
| 企業サムネ | 600×450 px | 4:3 |

### やり方

1. 上記フォルダに正しいファイル名でアップロード
2. コミット・プッシュ
3. 数分後、自動デプロイで反映

**画像が無い場合は自動的にテキストプレースホルダー（`[ 社名 サービス写真 ]` 等）が表示されます。** 画像を用意できたタイミングで、後からいつでも追加できます。

### 画像の差し替え

同じファイル名で上書きアップロードするだけ。ブラウザキャッシュが効いている場合は、`src/data/site.json` の `assetVersion` を新しい値（例：`20261015a`）に書き換えるとキャッシュがバスターされます。

## 2. 企業を追加する

### やること
1. `src/data/companies.json` の末尾に1ブロック追加
2. （任意）`public/images/companies/{id}.jpg` に画像を置く
3. コミット・プッシュ

### コピペ用テンプレート

```json
{
  "id": "newcompany",
  "name": "新しい会社",
  "category": "ihin",
  "rank": 7,
  "top": false,
  "catch": "キャッチコピー（1行）",
  "serviceType": "自社施工型",
  "intro": "紹介文。<strong>強調</strong>などのHTMLタグ可。",
  "features": [
    "特徴1",
    "特徴2",
    "特徴3"
  ],
  "specs": [
    { "label": "料金目安（公式）", "value": "1K 20,000円〜" },
    { "label": "サービス区分", "value": "自社施工型" },
    { "label": "対応エリア", "value": "全国" },
    { "label": "備考", "value": "追記事項" }
  ],
  "price": "1K 20,000円〜",
  "area": "全国",
  "editorNote": "",
  "hasReview": false,
  "affUrl": "",
  "asp": "",
  "shortType": "自社施工",
  "shortPrice": "1K 20,000円〜",
  "shortArea": "全国",
  "shortFeature": "短い特徴"
}
```

### フィールドの意味

| フィールド | 内容 |
|---|---|
| `id` | 半角英数（URL・ファイル名に使用）。例：`newcompany` |
| `name` | 会社名（表示用） |
| `category` | `ihin`（遺品整理・不用品回収）または `cleaning`（ハウスクリーニング） |
| `rank` | 表示順（1が最上位） |
| `top` | `true` にすると「編集部イチオシ」バッジ表示 |
| `catch` | キャッチコピー |
| `serviceType` | 「自社施工型」「紹介・加盟店型」など |
| `intro` | 紹介文（HTMLタグ可） |
| `features` | 箇条書きの特徴（配列） |
| `specs` | 情報テーブルの行（label と value のペア） |
| `hasReview` | `true` なら独自レビュー記事あり／`false` ならCTAだけのページになる |
| `affUrl` | アフィリエイトURL（空なら内部レビューページに自動リンク） |
| `asp` | ASP名の管理メモ（`a8`, `afb` など） |

### 追加すると自動で反映される場所

- `/rankings/ihin.html` または `/rankings/cleaning.html` の比較表と詳細ブロック
- `/reviews/{id}.html` が新規生成
- 全ページのサイドバー「ランキング」
- トップページのランキング（上位3社の場合）
- 見出しの「6社」のカウント

## 3. 企業を削除する

1. `src/data/companies.json` から該当ブロックを丸ごと削除
2. コミット・プッシュ

画像ファイル（`public/images/companies/{id}.jpg`）は残しておいてもOK（参照されないので害はない）。

---

## 4. 企業の情報を修正する

1. `src/data/companies.json` の該当箇所を編集
2. コミット・プッシュ

例：料金を変更したい → `specs` 内の該当行の `value` を書き換え、`shortPrice` も忘れずに更新。

## 5. アフィリエイトリンクを設定・変更する

`src/data/companies.json` の `affUrl` を書き換えるだけ。

### パターン別の挙動

| affUrl の値 | サイト上の挙動 |
|---|---|
| `""`（空文字） | 自社レビュー記事への内部リンクになる |
| `"https://track.a8.net/..."` など | 外部リンク＋`rel="sponsored nofollow noopener"`＋`target="_blank"` を自動付与 |

### 例：既存企業にA8リンクを設定

```json
{
  "id": "ihinnoseiriyasan",
  ...
  "affUrl": "https://track.a8.net/dc/xxxxx/xxxxx",
  "asp": "a8",
  ...
}
```

書き換えたらコミット・プッシュで即反映。

## 6. 記事を追加する

### やること

1. `src/content/articles/{slug}.html` を新規作成（記事本文）
2. `src/data/pages.json` の末尾に1ブロック追加
3. （任意）`public/images/categories/{slug}.jpg` にサムネイルを置く
4. コミット・プッシュ

### 記事本文のテンプレート

`src/content/articles/{slug}.html` の中身（例：`jikkajimai.html`）：

```html
<p class="lead">導入文。この記事で何がわかるかを100〜150字で。</p>

<div class="data-highlight">
  <div class="data-cell">
    <div class="num">数字<span class="unit">単位</span></div>
    <div class="label">説明</div>
  </div>
  <div class="data-cell">
    <div class="num">数字<span class="unit">単位</span></div>
    <div class="label">説明</div>
  </div>
  <div class="data-cell">
    <div class="num">数字<span class="unit">単位</span></div>
    <div class="label">説明</div>
  </div>
</div>
<p class="source-note">出典：〜</p>

<div class="toc">
  <div class="toc-title">目次</div>
  <ol>
    <li><a href="#section1">見出し1</a></li>
    <li><a href="#section2">見出し2</a></li>
  </ol>
</div>

<h2 id="section1">見出し1</h2>
<p>本文。<strong>強調</strong>や<a href="/rankings/ihin.html">内部リンク</a>可。</p>

<h2 id="section2">見出し2</h2>
<p>本文。</p>

<div class="article-cta">
  <p>まとめ的な誘導文。</p>
  <a href="/rankings/ihin.html" class="btn-cta">ランキングを見る<span class="arrow">→</span></a>
</div>
```

既存記事（`akutoku.html` など）をコピーして書き換えるのが早いです。

### pages.json への追加テンプレート

```json
{
  "slug": "jikkajimai",
  "type": "article",
  "title": "実家じまいの進め方｜相続前に家族で決めておくこと【2026年最新】",
  "description": "実家じまいをスムーズに進めるためのポイントを...",
  "catTag": "実家じまい",
  "h1": "実家じまいの進め方｜相続前に家族で決めておくこと",
  "meta": [
    "公開：2026年10月1日",
    "更新：2026年10月1日",
    "閲覧数：0"
  ],
  "keyPoints": [
    "重要ポイント1",
    "重要ポイント2",
    "重要ポイント3"
  ]
}
```

### フィールドの意味

| フィールド | 内容 |
|---|---|
| `slug` | 半角英数（URL・ファイル名に使用）。例：`jikkajimai` → `/articles/jikkajimai.html` |
| `type` | 記事は `"article"` |
| `title` | ブラウザタブ・SEO用タイトル |
| `description` | メタディスクリプション |
| `catTag` | カテゴリ表示ラベル |
| `h1` | ページ内のH1見出し |
| `meta` | 記事上部に表示する情報（公開日など） |
| `keyPoints` | サイドバーの「この記事の要点」に表示 |

### 追加すると自動で反映される場所

- `/articles/{slug}.html` が新規生成
- トップページの「新着・人気記事」カード
- 全ページのサイドバー（関連記事）

## 8. ナビゲーション（ヘッダー・フッター）を変更する

`src/data/site.json` を編集：

- `nav` … 上部ヘッダーメニュー
- `drawer` … スマホのメニュー（ハンバーガー）
- `footer` … フッターリンク

---

## 反映までの流れ

1. GitHub でファイルを編集・コミット・プッシュ
2. Cloudflare Pages が自動でビルド（数分）
3. `iihinseiri.com` に反映

ビルド状況は Cloudflare Pages のダッシュボード「デプロイ」タブで確認できます。

---

## トラブル時

- **ビルドが失敗した** → Cloudflare Pages のデプロイ詳細でログを確認。JSONの書式ミス（カンマ抜け、閉じ括弧忘れ）が原因のことが多い
- **画像が反映されない** → ファイル名・拡張子・フォルダ位置を再確認（英小文字・拡張子は `.jpg` 統一が安全）
- **ブラウザで古い表示が残る** → `src/data/site.json` の `assetVersion` を新しい値に書き換える

以上。
